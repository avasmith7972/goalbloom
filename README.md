# 🌸 GoalBloom — SMART Goal Tracker

A beautiful, feature-rich goal tracking app built with Next.js 15, React, and Tailwind CSS.

## ✨ Features

- 🎯 Set SMART goals with title, category, deadline & motivation
- 📊 Track progress with visual progress bar
- ✅ Break goals into milestones (checklist)
- 📝 Personal notepad for each goal
- 📅 Calendar view with deadline tracking
- 🌸 Personalised onboarding (name, avatar, interests)
- 💾 Data saved locally — no login required
- 📱 Mobile-friendly responsive design

## 🛠️ Tech Stack

- Next.js 15 (App Router)
- React + TypeScript
- Tailwind CSS
- localStorage for data persistence

## 🚀 How to Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
